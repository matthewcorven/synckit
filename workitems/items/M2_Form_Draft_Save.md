# M2: Form UI + draft/save

**Owner:** Agent A  
**Status:** Proposed  
**Dependencies:** M1

## Goal
Ship the on-screen representation of the left-half entry form with draft persistence.

## Scope
- Angular form layout aligned to the official template
- Create draft entry + update entry fields
- Grid UI for selections + save/restore

## Acceptance criteria
- Handler can create a draft, fill required fields, save, refresh, and see values persisted.
- Disabled grid cells cannot be selected.
